# Teaboom — карточка товара «Ананасовый улун»

Тестовое задание на позицию HTML/Frontend-верстальщика.

## Демо

Ссылка на опубликованную страницу: `<ссылка появится после деплоя>`

## Стек

- HTML5
- CSS3 (Grid, Flexbox)
- JavaScript (без фреймворков)

## Функциональность

- Переключение фасовки (100 г / 500 г / 1000 г / 5000 г) — меняются цена, старая цена, артикул и цвет карточки
- Кнопка «В корзину» превращается в счётчик с кнопками «−» и «+»
- Клик по картинке открывает её в модальном окне с размытым фоном
- Адаптивность: 1440px, 768px, 375px
